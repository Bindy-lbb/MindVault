# 第五阶段：评估与部署课程及实践顺序

[学习地图](../学习地图.md) · [卡片目录](../10-知识卡片/README.md) · [项目 05](../30-项目实践/05-评估与本地部署/README.md)

目标：让前面的学习工具有固定的评估题、运行步骤、版本记录与恢复办法。先完成离线评估和本机部署，再按需求选云端。资料核查：2026-10-29。

## 阅读与实践顺序

### 新手先读库内讲解

十张卡片都已补充通俗解释、完整示例、输入输出、常见疑问、练习答案与本库入口，核心内容可以在库内顺序学完，外部教程放到文末选读。

贯穿目标：**验证 API 密钥等笔记的检索效果，把检索程序作为本机服务运行，并能重启和恢复旧版本。**先分清检索指标、人工答案评分和运行可用性，再逐步动手。

## 这一阶段的技术选择

继续用 Markdown + Obsidian + GitHub，追加标准库评估脚本、JSON 报告、回环 HTTP 服务和本地发布目录。复用第三阶段关键词检索、第四阶段预写 Agent 情节，便于观察和复现。默认不生成真实模型答案、不联网下载模型、不公开知识库。

http.server 只用于本机教学。云端可进一步研究 FastAPI 的进程与 HTTPS 部署，或按 Datawhale/Streamlit 教程单独做应用界面；当前检索服务不能直接当作 Streamlit 应用上传。

## 我的完成标准

- [ ] 亲自跑 dev 评估，能解释来源命中、来源覆盖、原句覆盖的差别。
- [ ] 改一个参数，用同一题集比较；保留退步或仍失败的例子。
- [ ] 为真实 RAG/Agent 结果填写人工判断，未生成答案的项目不填正确率。
- [ ] 启动本机服务，按请求 ID 找到日志，确认日志没有问题正文。
- [ ] 停止、重启并查询同一问题；资料更新后验证索引过期与重建。
- [ ] 打包并校验，在最终目录建立索引，验证旧版本可恢复。
- [ ] 按[复盘模板](../30-项目实践/05-评估与本地部署/评估与发布复盘模板.md)记录证据与下一步。

资料准备与学习完成分开记录，实际检查范围见[运行检查记录](../30-项目实践/05-评估与本地部署/运行检查记录.md)。

用 AI 帮你解释指标、定位报错或修改一个配置；问题标签、结论、访问范围与恢复效果需要自己验证。课程内容公开可读不等于所有练习服务零成本。

### 云端与依赖选修

- [pip 可重复安装](https://pip.pypa.io/en/stable/topics/repeatable-installs/)与[Python venv](https://docs.python.org/3.13/library/venv.html)：为以后第三方依赖记录版本与安装来源；本项目无第三方运行依赖。
- [Streamlit 部署准备](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app)、[密钥管理](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management)、[应用分享](https://docs.streamlit.io/deploy/streamlit-community-cloud/share-your-app)：先核对文件组织、平台限制、可见性与账户条件；不承诺免费额度或私有应用数量永久不变。当前没有创建云应用。
