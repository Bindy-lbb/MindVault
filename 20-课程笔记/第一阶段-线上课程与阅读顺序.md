## 本次配套项目

[项目 01：Markdown 读取与 JSON 保存](../30-项目实践/01-Markdown读取小程序/README.md)把这些概念串起来：

读取一篇笔记 → 组成字典 → 显示结果 → 另存 JSON → 读回确认。

这个项目使用已有 Python 和标准库，不需要模型账号或显卡。它为阶段 2 的“把正文发送给模型”准备输入处理能力。

## 我应该怎样参考课程

先跟一条主线，其他资料用于查规则或换一种解释。每次学完一个小节，换成自己的标题、笔记或输入重做一次，把运行结果和仍不懂的问题记下来。
