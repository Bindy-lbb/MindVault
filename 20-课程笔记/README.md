## 如何记录

记录课程、文章、论文等学习材料。建议用课程或文章标题命名，系列课程可以再建子文件夹。

使用 [课程笔记模板](../80-模板/课程笔记模板.md)，重点写清楚：

- 材料来源和阅读日期。
- 这次学习要回答的问题。
- 核心内容与自己的理解。
- 实践结果和还没弄懂的地方。

学完后，把能独立解释的概念整理成知识卡片，再在课程笔记里链接到它。
