# 实践运行约定与排错

[学习总导航](../学习总导航.md) · [实践目录](../30-项目实践/README.md) · [学习状态规则](学习状态与Bases看板.md)

## 从哪里输入命令

Obsidian 用于读写笔记。标为 `powershell` 的代码块在 PowerShell 终端运行；标为 `python` 的例子在 Python 解释器或 `.py` 文件里运行。复制时不要带上代码围栏，也不要把提示符 `>>>` 当成代码。

实践页面的第一段 PowerShell 命令从以下位置开始：

```powershell
Set-Location 'E:\my-projects\MindVault'
$env:PYTHONUTF8 = '1'
python --version
```

更换仓库位置后修改 Set-Location 的路径。PYTHONUTF8 让新启动的 Python 使用 UTF-8，减少中文终端与重定向差异；文件本身也应按项目规定使用 UTF-8。

## 同一终端与新终端

`$ragScript`、`$agentScript`、`$stage5`、`$advanced` 等是当前 PowerShell 会话的变量，不会因为上一页设置过就自动出现在新终端。每篇实践的首个命令块都重新设置所需变量；后续代码块默认在同一会话继续。另开终端时，先重新执行相关初始化。

项目 03 的第二项实践要先建立指定索引；项目 05 的 serve 要先 index；真实训练 evaluate 要先有完整训练产物。每个文件名有依赖关系，不能只复制最后一条命令。

服务保持在第一个终端运行，第二个终端发送 HTTP 请求。第二个终端不会继承第一个终端的变量；直接用完整 URL 的请求不依赖这些变量。服务终端按 Ctrl+C 停止；本库未配置常驻或自动重启。

## 输出目录与重复练习

索引、日志、模型缓存和原始实验结果默认留在被 Git 忽略的 `.local/`。有的配置文件把 `.local` 解释为项目子目录内的位置，具体按配置页核对，不全部视为仓库根目录。

| 输出情况 | 正确处理 |
| --- | --- |
| 提示输出已存在 | 换新文件或新目录名，保留旧结果 |
| 将 v1 改成 v2 | 后面读取、比较和启动时使用同一套新名称 |
| 索引过期 | 用新索引名重建，核对资料与配置 |
| Obsidian 树里没有 .local | 用编辑器查看，复盘中记录路径；核对后另存正式笔记 |
| 想在 Obsidian 读生成结果 | 选择新的 `50-学习复盘/` 输出位置，按对应项目支持的文件/目录格式传参 |

当前项目拒绝覆盖已有输出，不需要删除原笔记来重复练习。输入、索引、结果三者应能区分。

## 发布包为什么保留 -B

项目 05 的发布清单只允许包内 `.local/` 存放变化的运行数据。Python 导入模块时可能创建 `__pycache__`，它会成为清单外文件。因此发布包的建索引和启动命令使用 `python -B`，生成的 START.md 也采用相同写法。

如果已经生成了缓存，不要删除原始代码或随意放宽校验。可换一个新的发布目录，按 `-B` 步骤重做；保留旧实验的失败记录即可。

## 什么才算这次做过

| 方式 | 实际动作 | 记录重点 |
| --- | --- | --- |
| preview | 构造请求，不调用生成模型 | 输入、设置，效果写未实测 |
| mock / fixture | 固定响应，执行结果处理 | 保存和校验，不能报告真实生成速度 |
| scripted | 预写响应驱动真实本地工具 | 调用、回执、预算，不能称真实模型决策 |
| 关键词 / extractive | 本地检索和摘录 | 来源、行号和检索指标 |
| live | 真实服务推理 | 实际模型、输出、用量与失败 |
| 小矩阵训练 | 真正优化玩具 A/B | 数值误差、保存重载，不能称 LLM 微调 |
| LoRA plan | 数据和配置检查 | 没加载模型、没验证真实 Tokenizer |
| LoRA train / evaluate | 显式加载模型并训练或评估 | 环境、基座、数据隔离、产物与人工判断 |

语义检索、LangGraph、Ollama 和真实微调需要额外条件，不在离线基础流程中自动安装。阅读相应卡片不要求先运行这些扩展。

## 出错先查哪一层

先保存命令、当前目录、模式、输入与输出名称，再看异常类型或 HTTP 状态。路径缺失先查文件；输出存在换新名；401 查认证；429 查当前服务限制；资料过期重建索引。不要把所有问题统一当“无答案”或反复重试。

loop 场景故意触发预算结束，退出码 2 是预期的受控失败；它证明预算生效，不证明复习题已生成。校验通过也仍需检查内容是否支持结论。

问题定位后，回到[学习总导航的排错入口](../学习总导航.md#卡住时回到哪里)，再把实际结果写到[学习复盘](../50-学习复盘/README.md)。
