## 外部链接如何判断

初查去掉页内片段后共有 104 个不同的外部地址：102 个返回 HTTP 200，其中 1 个是提示页面不存在的 LoRA 占位页；1 个是私有仓库；1 个是微信交互页面。

旧 LoRA 地址已经替换成原本也在库中使用的[PEFT LoRA main 页面](https://huggingface.co/docs/peft/main/en/conceptual_guides/lora)，因此修正后去重地址减少一个。正常重定向没有视为失效，例如 MCP 官方入口跳到具体文档版本。

私有 MindVault 仓库通过已登录的 GitHub API 验证可访问且仍为 private，没有按匿名请求的结果判断失效。微信原文需要交互访问，本次不宣称自动验证通过，也没有把它标成已失效；保留原始出处，正文借鉴内容已有库内整理。

HTTP 可访问只证明这次能够取得页面，不代表页面内容永久不变或所有外部页内锚点都有效。教程执行时仍按安装版本和官方文档核对；本次发现的占位页已额外人工确认。
