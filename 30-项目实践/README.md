## 如何记录

每个项目可以建一个子文件夹，放项目记录、少量代码和示例。已有独立代码仓库时，在这里保留链接即可。

使用 [项目实践模板](../80-模板/项目实践模板.md)，记录目标、环境、操作、结果和复现方法。

先选一个能做完的小项目，例如：整理一份学习材料、调用一次模型 API，或者对几篇笔记做搜索。记录失败尝试也有价值。

模型权重、大型数据集和依赖目录不适合直接放进笔记仓库；保存下载来源与运行步骤即可。API 密钥保存在本地环境配置中。
