# 实践二：带引用问答与评估

[项目入口](README.md) · [上一项](实践一-加载切分与关键词检索.md) · [下一项](实践三-语义检索与索引更新.md)

以下从仓库根目录运行，先完成实践一的 keyword-v1 索引。

## 1. 看原文摘录，不花模型费用

```powershell
$ragScript = '.\30-项目实践\03-RAG知识库问答\rag_practice.py'
python $ragScript ask --index '.local/rag/keyword-v1.json' --question 'API 密钥放在哪里？' --output '.local/rag/extract-v1.md'
python $ragScript ask --index '.local/rag/keyword-v1.json' --question '土星光环倾角多少？' --output '.local/rag/unknown-v1.md'
```

第一份记录明确写“原文摘录”，含路径、行号与检索分数。第二份应标记 `local_abstention`，无模型用量。“当前检索依据不足”不等于已经证明全库没有答案。

`.local` 是隐藏目录，Obsidian 通常不在文件树展示它。可另跑一次，把 `--output` 换为新的 `50-学习复盘/我的RAG摘录.md`，再按 `Ctrl+O` 打开；程序会按保存位置生成来源链接。核对后再决定是否提交，索引仍留在 `.local`。

## 2. 预览即将给模型的材料

```powershell
python $ragScript ask --index '.local/rag/keyword-v1.json' --question 'API 密钥放在哪里？' --mode preview
```

找到 system 里的任务边界、user 里的问题和 S1 等来源。资料里即使出现指令，也应作为资料阅读。不要把真实密钥放进问题；请求预览可能包含私人正文，谨慎分享截图。

## 3. 准备好后自行做真实问答

真实调用可跳过；本次整理未代为调用。它会把**问题与选中片段**发送到 DeepSeek，按账户规则计费。先核对 [JSON 输出指南](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)及当前模型支持。

```powershell
$ragKey = Read-Host '请输入自己的 DeepSeek API Key（不回显）' -AsSecureString
$env:DEEPSEEK_API_KEY = [System.Net.NetworkCredential]::new('', $ragKey).Password
$env:DEEPSEEK_MODEL = 'deepseek-flash'
python $ragScript ask --index '.local/rag/keyword-v1.json' --question 'API 密钥放在哪里？' --mode live --output '.local/rag/answer-v1.md'
```

需要项目 02 的 `model_api.py` 保留在原目录。网络等待 60 秒，不自动重试。认证、网络、截断、空回答或引用校验失败都会报错；不要把失败当成已生成可靠答案，也不要反复盲目重试。

本练习让模型返回 `answer`、`citations`、`insufficient_evidence`。程序检查引用 ID 与原句，人工仍要核对“这句依据是否支持答案”。返回的 usage 原样记录，不编造 Token 或金额。

结束后可清理当前终端变量：

```powershell
Remove-Item Env:DEEPSEEK_API_KEY -ErrorAction SilentlyContinue
Remove-Variable ragKey -ErrorAction SilentlyContinue
```

## 4. 跑检索评估

```powershell
python $ragScript evaluate --index '.local/rag/keyword-v1.json' --top-k 3 --output '.local/rag/eval-k3.json'
python $ragScript evaluate --index '.local/rag/keyword-v1.json' --top-k 1 --output '.local/rag/eval-k1.json'
```

内置 6 题：5 题有目标来源，1 题资料外。结果计算**来源级** Hit@K、MRR@K，并单独记录资料外题是否返回候选。没有调用模型，不计算答案正确率。当前样例短小、原词明显，成绩不能外推到整个 MindVault。

扩展自己的 JSON 题集：每题写 `question` 和 `expected_sources`；来源路径相对资料目录，资料外题用空数组。使用 `--questions '你的题集.json'`。加入同义改写、多笔记综合、冲突版本以及“检索到了却不能回答”的问题；人工标注支持答案的具体行。
