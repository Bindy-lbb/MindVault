# 实践三：语义检索与索引更新

[项目入口](README.md) · [上一项](实践二-带引用问答与评估.md)

先完成关键词基线，再做这项选修。关键词索引不需要下载任何模型；语义路径使用真实本地 Embedding。此次检查没有下载权重或运行真实语义模型。

运行前可看[统一运行约定与排错](../../40-工具手册/实践运行约定与排错.md)：从仓库根目录开始，首次代码块设置会话变量；新终端需重新设置。输出使用新名称，预期失败不记作成功。

## 1. 安装选修依赖

在仓库根目录新建独立环境，无须先激活：

```powershell
Set-Location 'E:\my-projects\MindVault'
$env:PYTHONUTF8 = '1'
python -m venv '.local/rag-venv'
$ragPython = '.\.local\rag-venv\Scripts\python.exe'
& $ragPython -m pip install sentence-transformers
& $ragPython -m pip freeze > '.local/rag-dependencies.txt'
$ragScript = '.\30-项目实践\03-RAG知识库问答\rag_practice.py'
```

若当前 Python 与依赖没有可用构建，按报错核对 PyTorch / Sentence Transformers 的支持版本后换环境，不修改全局 Python。安装结果记录在本地；当前没有提供已验证的依赖锁文件。

模型为 [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)，固定 revision `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`，来源为[官方仓库元数据](https://huggingface.co/api/models/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)（2026-10-23 核查）。CPU 编码，不开启远程自定义代码；首次运行会下载权重，需网络、磁盘与内存。未测本机耗时，不承诺速度。

模型输入长度有限，编码前会检查；不会静默截断。先用每块 3 行、无重叠；若仍超限，按提示缩短文本或改变切分。短切分也可能损失上下文，需评估。

## 2. 真正建立向量索引

```powershell
& $ragPython $ragScript build --backend semantic --chunk-lines 3 --overlap-lines 0 --index '.local/rag/semantic-v1.json'
& $ragPython $ragScript search --index '.local/rag/semantic-v1.json' --question '钥匙应该存哪儿？' --top-k 3
& $ragPython $ragScript evaluate --index '.local/rag/semantic-v1.json' --output '.local/rag/eval-semantic-v1.json'
```

向量在本机计算并保存，查询使用相同模型版本，再用归一化向量点积排序。没有云端 Embedding 请求，没有部署向量数据库。语义相似度通常不为零，因此资料外题也可能返回候选；结合 min-score 实验与生成拒答，不能套用关键词的零命中预期。

公平对照时另建相同切分的关键词索引：

```powershell
python $ragScript build --chunk-lines 3 --overlap-lines 0 --index '.local/rag/keyword-3lines.json'
python $ragScript evaluate --index '.local/rag/keyword-3lines.json' --output '.local/rag/eval-keyword-3lines.json'
```

模型词长限制可能导致评估问题超长，需同样检查。`--min-score 0.3` 只能作为一次试验值，不是通用相关性门槛；用验证题调参，再保留新题检查效果。

## 3. 修改资料，验证索引更新

先在 `.local/update-notes/` 复制配套示例或自己的实验笔记，避免改动原件：

```powershell
New-Item -ItemType Directory -Path '.local/update-notes' -Force
Copy-Item -LiteralPath '.\30-项目实践\03-RAG知识库问答\examples\notes\01-API配置.md' -Destination '.local/update-notes/'
python $ragScript build --corpus '.local/update-notes' --index '.local/rag/update-v1.json'
```

用文本编辑器在副本里添加一句“本次实验编号为 RAG-2026-A”，保存后查询旧索引：

```powershell
python $ragScript search --index '.local/rag/update-v1.json' --question '实验编号是什么？'
python $ragScript build --corpus '.local/update-notes' --index '.local/rag/update-v2.json'
python $ragScript search --index '.local/rag/update-v2.json' --question '实验编号是什么？'
```

旧索引应提示资料变化并拒用，v2 应能找到新增原句。再尝试新增、删除一篇**实验副本**，观察相同保护。源文档已变化时旧行号也会失效，需要重新生成问答记录。
