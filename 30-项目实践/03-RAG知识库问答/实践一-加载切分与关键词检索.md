# 实践一：加载、切分与关键词检索

[项目入口](README.md) · [下一步：引用问答](实践二-带引用问答与评估.md)

目标：不用密钥和第三方库，观察真实文件如何变成检索片段。先读[加载与元数据](../../10-知识卡片/文档加载与元数据.md)和[切分](../../10-知识卡片/文档切分与重叠.md)。

## 1. 建立第一个索引

从仓库根目录执行，各次练习沿用本页变量：

```powershell
$env:PYTHONUTF8 = '1'
$ragScript = '.\30-项目实践\03-RAG知识库问答\rag_practice.py'
python $ragScript build --index '.local/rag/keyword-v1.json' --chunk-lines 8 --overlap-lines 2
```

默认只读取配套五篇示例。输出应显示 5 篇、6 个片段。打开 `.local/rag/keyword-v1.json`，找 `manifest`、`chunks` 中的 `path`、`title`、`start_line`、`end_line`、`text`。title 取文档第一个一级标题，缺少时用文件名；行号从 1 开始，首尾都包含。

索引创建于 `.local/`，文件中包含原文，不能随意分享。不要往示例目录放密钥。

## 2. 真正检索一次

```powershell
python $ragScript search --index '.local/rag/keyword-v1.json' --question 'API 密钥放在环境变量中吗？' --top-k 3 --output '.local/rag/search-v1.json'
```

查看前几条 `hits`：是否命中 `01-API配置.md`？打开原文件，核对片段行号和逐字内容。分数表示本算法的字面重合程度，不是模型的把握程度。

## 3. 做两个对照

```powershell
python $ragScript search --index '.local/rag/keyword-v1.json' --question '钥匙应该存哪儿？' --top-k 3
python $ragScript search --index '.local/rag/keyword-v1.json' --question '土星光环倾角多少？' --top-k 3
python $ragScript build --index '.local/rag/keyword-small.json' --chunk-lines 4 --overlap-lines 1
```

同义改写可能漏检；资料外问题预期无匹配。用相同问题查询 small 索引，比较是否把条件与结论切开。若未来修改示例，预期结果也要重新检查。

## 4. 换成自己的笔记

在仓库根目录 `.local/my-rag-notes/` 手工复制 5–10 篇允许用于实验的 Markdown，先看清内容。保留原笔记，不复制 `.env`、附件或整个工作目录。

```powershell
python $ragScript build --corpus '.local/my-rag-notes' --index '.local/rag/my-notes-v1.json'
python $ragScript search --index '.local/rag/my-notes-v1.json' --question '换成你知道资料中有答案的问题'
```

脚本仅处理 `.md`，跳过隐藏目录及常见依赖目录，不跟随指向资料目录外的文件链接。只有一个汉字的问题可能没有中文双字特征；尝试更完整的问题。
