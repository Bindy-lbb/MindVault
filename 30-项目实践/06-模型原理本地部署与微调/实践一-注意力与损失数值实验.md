# 实践一：注意力与损失数值实验

[项目入口](README.md) · [下一项](实践二-小矩阵LoRA与适配器.md)

目标：用小数字看见一个计算步骤，不下载模型。先读[矩阵](../../10-知识卡片/张量与矩阵运算.md)、[因果注意力](../../10-知识卡片/自注意力与因果掩码.md)与[梯度](../../10-知识卡片/损失函数与梯度更新.md)。

## 1. 运行实验

从仓库根目录执行：

```powershell
$env:PYTHONUTF8 = '1'
$advanced = '.\30-项目实践\06-模型原理本地部署与微调'
python "$advanced\principles_lab.py" --output '.local/advanced/principles-v1.json'
```

Q、K、V 都是3×2教学矩阵，每一行代表一个位置的两个数值特征，不是真实词向量。脚本计算缩放点积，只对当前位置及之前的位置做 softmax，再与 V 相乘。

## 2. 看三个现象

- 第一行只能参考自己，权重为 `[1, 0, 0]`。
- 每行权重和接近1，未来位置的权重严格为0。
- 输出仍是3×2，但每一行可能是过去多个位置的加权组合。

用手算核对一个乘积。这个实验不包含多头、位置编码、残差、前馈网络或整个 Transformer；不能用它代表完整模型性能。

## 3. 看交叉熵更新

prediction 中 logits 初始为 `[2,0,-1]`，目标下标为1。观察 probabilities、gradient 和更新后的 loss。这里直接更新 logits，只演示目标概率与梯度关系；真实模型会通过反向传播更新指定权重。

再比较另一种学习率：

```powershell
python "$advanced\principles_lab.py" --learning-rate 0.8 --output '.local/advanced/principles-lr08.json'
```

这个简单例子的一步损失降低，不保证任意网络、任意学习率都能下降。

## 4. 自己改一次

把脚本副本放在本地实验目录，再修改一个 Q 或 V 数字，观察对应输出；不要同时改公式与输入。想继续写 PyTorch 版，可对照[张量教程](https://docs.pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html)和[Autograd](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)，在独立环境安装，不影响本练习。
