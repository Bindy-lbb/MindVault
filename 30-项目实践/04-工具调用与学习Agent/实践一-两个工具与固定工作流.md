# 实践一：两个工具与固定工作流

[项目入口](README.md) · [下一项](实践二-Agent循环与真实工具调用.md)

目标：先确认工具真的有用，再让模型选择工具。本练习不用密钥、不联网、不安装第三方依赖。

## 1. 单独搜索

从仓库根目录运行：

```powershell
$env:PYTHONUTF8 = '1'
$agentScript = '.\30-项目实践\04-工具调用与学习Agent\study_agent.py'
python $agentScript --mode tool --tool search_notes --query 'API 密钥环境变量'
```

结果中找 `ok`、`note_id`、标题和行号。默认资料来自第三阶段五篇示例；查询时没有调用生成模型。excerpt 最多 600 字符，`excerpt_truncated` 表示是否截短，不能把摘要当成全文。

## 2. 按行读取

```powershell
python $agentScript --mode tool --tool read_note --note-id '01-API配置.md' --start-line 1 --end-line 8
```

打开[API 配置原文](../03-RAG知识库问答/examples/notes/01-API配置.md)，核对前 8 行。首尾行均包含。工具 ID 是资料目录内的相对文件名，不接受任意绝对路径。

试一个失败：

```powershell
python $agentScript --mode tool --tool read_note --note-id '不存在.md' --start-line 1 --end-line 8
python $agentScript --mode tool --tool read_note --note-id '01-API配置.md' --start-line 8 --end-line 1
```

分别预期 `unknown_note` 与 `invalid_arguments`，退出码非零。再搜索“土星光环倾角”：应该是正常成功但结果为空。空结果和执行错误不是同一件事。

## 3. 跑固定工作流

```powershell
python $agentScript --mode workflow --query 'API 密钥环境变量' --output '.local/agent/workflow-v1'
```

看 trace.json：代码固定先搜索 1 条，再读取对应行。result.md 展示原文，不声称生成了复习题。这个流程可以处理不同 query，但不知道你在自然语言任务里想要几道题。

## 4. 换成自己的资料

先在 `.local/agent-notes/` 手工复制 5–10 篇允许使用的笔记，再运行：

```powershell
python $agentScript --mode workflow --corpus '.local/agent-notes' --query '你的笔记中有的术语' --output '.local/agent/my-workflow-v1'
```

`--corpus` 只对 tool/workflow/preview/live 使用自己的资料；scripted 固定默认示例。当前继承第三阶段教学上限：最多 100 篇，单篇 200000 字节，总文本 200000 字符。索引在内存中建立，每次启动新快照，不依赖之前生成的索引文件。

## 验收

- [ ] 工具结果能回到原文和行号。
- [ ] 能区分空结果、参数错误、未知笔记。
- [ ] 能解释为何固定流程不是本次模型动态决策。
