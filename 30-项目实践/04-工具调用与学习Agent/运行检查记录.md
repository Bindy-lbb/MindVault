## 检查覆盖

- 默认只载入第三阶段五篇示例；搜索标题、来源、行号正确，读取与原文逐字对应。
- 缺失/额外字段、错误类型、布尔值冒充整数、查询与行号越界等参数被拒绝；空查询结果与执行错误分开返回。
- 未登记工具、不在清单中的笔记、目录穿越形式及绝对路径 ID 均未执行读取。
- 引文必须来自对应 note_id 的成功读取内容；伪造引文、未读来源、字段错误、条数越界被拒绝。
- assistant/tool 调用 ID 配对与下一轮消息回传正确；重复 ID、无效工具列表、截断响应和错误角色被拒绝。
- 单轮两个工具调用按顺序执行并回传；工具次数与请求轮数分别限制。
- 请求失败保留错误记录；最终缺少已读依据或协议无效时停止。消息字符预算校验生效。
- 运行期间实验副本新增、修改、删除会使资料版本检查失败；超过 6000 字符的读取被拒绝。
- 实验副本中的指令性文字只是正文；未登记函数返回 unknown_tool。这不等于已实测真实模型对所有提示注入的抵抗力。
- 命令行预览、固定流程、各脚本情节、预算退出、密钥缺失、已有结果不覆盖、结果中的原文件链接均通过检查。
- 两个 Python 文件语法检查通过；LangGraph 文件只检查语法，未安装或调用真实框架。
