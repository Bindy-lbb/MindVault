# 项目 02：模型 API 与文章整理

[项目目录](../README.md) · [第二阶段课程](../../20-课程笔记/第二阶段-模型API课程与实践顺序.md) · [学习地图](../../学习地图.md)

## 要做出什么

先完成一句话问答，再读取本地文章正文，将返回结果校验后保存为 Markdown 草稿。两项练习共用 [model_api.py](model_api.py)。

1. [实践一：首次 API 调用](实践一-首次API调用.md)。
2. [实践二：文章整理工具](实践二-文章整理工具.md)。

本项目为 MindVault 自编，参考 Datawhale 的课程思路、DeepSeek 当前接口与 Python 标准库文档。项目使用已有 Python，无第三方依赖。

## 三种模式

| 模式 | 做什么 | 需要密钥 / 是否请求模型 |
| --- | --- | --- |
| `preview`，默认 | 在终端展示将发送的请求 | 不需要 / 不请求 |
| `mock` | 使用明确标记的固定教学结果，练习解析与保存 | 不需要 / 不请求 |
| `live` | 一次真实 HTTP 请求，失败时没有自动重试 | 需要本地设置 / 请求 DeepSeek |

真实调用会按服务规则计费；整理任务会发送你选择的正文。`--source-url` 只保留原文链接，不负责抓取网页。

## 先看请求

在 PowerShell 中逐条执行：

```powershell
Set-Location 'E:\my-projects\MindVault'
python '.\30-项目实践\02-模型API与文章整理\model_api.py' hello
python '.\30-项目实践\02-模型API与文章整理\model_api.py' summarize
```

第一条预览问答请求，第二条默认读取配套的 [示例文章](examples/示例文章.md)并预览整理请求。预览不会写文件。

## 看懂程序的几个位置

| 函数 | 负责什么 |
| --- | --- |
| `build_payload` | 组织消息和参数 |
| `call_api` | 构造认证与 HTTP 请求，处理网络错误 |
| `mock_response` | 提供本地教学数据，仅与配套样文搭配 |
| `extract_answer` | 检查结束原因和回答内容 |
| `validate_summary` | 解析 JSON，检查字段和原文依据片段 |
| `render_note` | 生成有调用记录的待核对草稿 |

初学时先看 `build_payload`、示例数据和输出，再沿函数名逐步阅读。脚本逐次处理一项任务，当前不涉及多轮会话、流式输出、网页抓取或工具调用。

## 练习规则

- `hello` 的输出文件使用 `.json`，`summarize` 使用 `.md`。
- `mock/live` 必须指定新的输出路径；已有文件或与输入相同的路径会在调用前被拒绝。
- 整理正文使用 UTF-8，教学输入上限为 20000 字符，输出设置范围为 1–4096 Token；这是本地练习限制。
- 所有结果先放 `.local/stage2/`，核对后再选择保存为正式笔记。
- 模拟结果的 `usage` 为 `null`，真实返回的用量按原字段保留，不自行编造金额。
