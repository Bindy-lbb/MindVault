# 张量与矩阵运算

[卡片目录](README.md) · [进阶课程](../20-课程笔记/进阶阶段-模型原理本地部署与微调.md)

## 一句话解释

**张量是按一定形状排列的数值，矩阵是二维张量；矩阵乘法把输入特征组合成新的特征。**可以先把它当成一张有明确行列含义的表，不必一开始就掌握所有高维运算。

## 为什么需要它

模型接收的是数值，不是电脑屏幕上的字。文字编码后，通常还要变成向量，再经过许多矩阵运算。看懂“形状”有助于知道哪些数能一起计算，也能读懂常见维度报错。

大模型的参数可以包括矩阵中的权重值；训练调整这些值，推理用它们计算。输入数据和模型权重都可能是张量，但用途不同。

## 用 MindVault 走一遍

先不用真实分词器，把三段文字的两个特征记成教学矩阵 X。这里只是自写数值，不宣称某一列真代表“语义”或“知识”。

```text
X = [[1, 2],       W = [[1, 0, 2],
     [3, 4],            [0, 1, 1]]
     [5, 6]]
```

X 的形状是 3×2，W 是 2×3，所以 XW 是 3×3。每个输出元素来自一行与一列逐项相乘再求和：第一行第三列为 `1×2+2×1=4`。完整结果是 `[[1,2,4],[3,4,10],[5,6,16]]`。

| 名称 | 例子 | 形状理解 |
| --- | --- | --- |
| 标量 | 一个损失值 0.5 | 一个数 |
| 向量 | 一个 Token 的特征列表 | 一条数列 |
| 矩阵 | 多个位置的特征表 | 行和列 |
| 三维张量 | 多条序列的特征 | 批次×长度×隐藏维度 |

例如 batch=2、序列长度=3、隐藏维度=4，共 2×3×4=24 个数。batch 是一次一起处理多少条样本；长度是每条序列的位置数；隐藏维度是每个位置的特征数。这些是教学尺寸，不是项目所用 Qwen 的实际配置。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 明确含义 | 每个轴表示什么 | 形状标注 |
| 检查乘法 | 左矩阵列数、右矩阵行数 | 相等才可普通矩阵相乘 |
| 计算 | 一行与一列 | 输出一个元素 |
| 扩展所有行列 | X 为 m×n、W 为 n×p | m×p 结果 |
| 核对 | 手算元素与程序输出 | 排除形状或计算错误 |

转置 Wᵀ 是交换行列，不是求倒数。逐元素乘法也不是这里的矩阵乘法；不要因都写“乘”就混用。

## 常见疑问

**一行特征能直接解释成几个中文标签吗？**通常不能。真实隐藏特征是学习得到的分布式表示，不必与人能命名的概念一一对应。

**维度越大越好吗？**更大维度通常需要更多参数和计算，但是否适合任务仍看模型、数据与评估。

**Python 列表就是 PyTorch 张量吗？**不是。本库用列表演示二维运算，没有设备迁移、自动求导、广播等完整能力。

**参数数量等于矩阵行数吗？**不是。一个 m×n 的权重矩阵有 m×n 个元素；完整模型还包含许多其他矩阵和参数。

## 小练习与自测

**题目：**3×2 与 3×4 能直接做普通矩阵乘法吗？

**参考答案：**不能，内部维度 2 和 3 不匹配。若第二个矩阵为 2×4，输出才是 3×4。

**练习：**把 X 第一行改成 [2,1]，新的第一行是 [2,1,5]。先手算再用实践一的 matmul 核对。
