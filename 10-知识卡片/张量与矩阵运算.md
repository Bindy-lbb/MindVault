# 张量与矩阵运算

[卡片目录](README.md) · [进阶课程](../20-课程笔记/进阶阶段-模型原理本地部署与微调.md)

## 一句话解释

**张量是有形状的数值容器；矩阵是二维张量，矩阵乘法把一组特征组合成另一组特征。**

## 用例与边界

像把每个词的几个特征排成表格。若输入 X 是 3×2，权重 W 是 2×4，XW 就是 3×4；中间的 2 必须匹配。

大模型里常见 batch、序列长度、隐藏维度。形状标注能帮助判断数据流，不能把矩阵乘法当成逐元素相乘。实践一用 Python 列表演示二维运算，并没有实现 PyTorch 的全部张量能力。
