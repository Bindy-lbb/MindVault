# 列表与字典

[知识卡片目录](README.md) · [学习地图](../学习地图.md)

## 一句话解释

**列表按顺序放一组值，字典按“名称 → 值”组织信息。**列表适合记录一批笔记，字典适合描述一篇笔记的多个字段。[参考：Python 数据结构](https://docs.python.org/zh-cn/3.13/tutorial/datastructures.html)

## 用生活里的事理解

列表像一排编号抽屉，按位置取；字典像有字段名的信息表，按名称取。

## 一个具体例子

```python
titles = ["Token", "JSON"]
note = {"title": "Token", "reviewed": False}

print(titles[0])
print(note["title"])
note["reviewed"] = True
print(note["reviewed"])
```

这份自拟示例依次输出 `Token`、`Token`、`True`。

| 操作 | 含义 |
| --- | --- |
| `titles[0]` | 取列表第一项，下标从 0 开始 |
| `titles.append("API")` | 在列表末尾追加一项 |
| `note["title"]` | 按键名取标题 |
| `note["reviewed"] = True` | 修改这个字段的值 |

## 放到 MindVault 中有什么用

读取笔记后，可以用一个字典保存标题、正文和字符数。读取多篇时，再用列表保存多个这样的字典；后续可以转换为 [JSON](JSON.md)。

## 容易误解的地方

- 列表第一个位置是 `0`，不是 `1`。
- 取超出范围的列表下标会报错；直接取不存在的字典键也会报错。
- Python 字典和 JSON 文本需要通过相应工具转换，不能只看外观相似就当作同一种东西。
