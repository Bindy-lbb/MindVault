# 自注意力与因果掩码

[卡片目录](README.md) · [进阶课程](../20-课程笔记/进阶阶段-模型原理本地部署与微调.md)

## 一句话解释

**自注意力让每个位置按相关程度组合序列中的信息；因果掩码让当前位置只看自己与前文。**可以把它理解为读一句话时，为当前理解挑选相关线索，而不能偷看尚未生成的后文。

## 为什么需要它

模型不仅要处理“有哪些词”，还要根据上下文组合信息。例如“它”指代什么，需要参考前文。注意力提供可学习的信息汇总机制。

生成模型训练时常一次看到整段样本，但预测下一 Token 不能利用未来答案。掩码让并行训练遵守逐步生成的可见范围。

## 用 MindVault 走一遍

Q 是当前位置的查询表示，K 是各位置供匹配的键，V 是要汇总的值。这里是向量，不是自然语言搜索词或外部数据库。

简化单头公式是 `softmax(QKᵀ / √d + mask) V`：先打分，缩放，再屏蔽未来，转换为权重，最后加权汇总 V。

本库实践一让 Q=K=V，三行分别是 [1,0]、[0,1]、[1,1]，特征宽度 d=2。第二个位置只可看前两个，打分为 [0,1/√2]，softmax 后约 [0.3302,0.6698]，第三个位置权重为 0。输出约为 [0.3302,0.6698]。

| 查询位置 | 允许看位置 | 未来位置权重 |
| --- | --- | --- |
| 第 1 个 | 1 | 第 2、3 个为 0 |
| 第 2 个 | 1、2 | 第 3 个为 0 |
| 第 3 个 | 1、2、3 | 没有未屏蔽的未来 |

第一行只剩一个候选，权重就是 [1,0,0]。每行权重和为 1。代码直接只对允许位置做 softmax，再补 0，等价于这个例子的未来分数设为负无穷；不要把未来分数设为普通 0 后一起做 softmax，那样仍可能分到权重。

真实模型通常用学习到的不同投影生成 Q/K/V，还有多头和位置处理；本库相等的小矩阵仅为看清计算。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 形成 Q/K/V | 每个位置的表示 | 查询、键、值矩阵 |
| 匹配 | Q 与 K | 每对位置的分数 |
| 缩放和屏蔽 | 分数、宽度、可见规则 | 合法位置的分数 |
| 归一化 | 分数 | 每行和为 1 的权重 |
| 汇总 | 权重与 V | 各位置的新表示 |

掩码按位置限制可见性，不是把所有未来词从整个训练文件中删除。

## 常见疑问

**有因果掩码就能保证事实正确吗？**不能。它控制信息可见性，不判断事实或来源。

**注意力权重大就是完整解释吗？**权重只反映这个计算步骤，不能独自证明模型最终回答的因果理由。

**训练为什么可以并行算多个位置？**参考序列已经提供，掩码让每个位置只使用合法前缀；生成时未来 Token 未知，还要逐步决定。

**所有 Transformer 都只看前文吗？**不是。这里针对自回归因果语言模型；编码器等结构可用不同可见规则。

## 小练习与自测

**题目：**把第二行的第三个权重设为 0，是否还需要重新归一化？

**参考答案：**先屏蔽再对合法分数做 softmax，能自然保证权重和为 1；若事后随意置零，剩余权重可能不再和为 1。

**练习：**运行实践一，核对右上角为 0，每行和为 1。再改第一行 V，观察后面允许读取它的位置如何变化。
