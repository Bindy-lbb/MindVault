# 微调超参数与过拟合

[卡片目录](README.md) · [进阶课程](../20-课程笔记/进阶阶段-模型原理本地部署与微调.md)

## 一句话解释

**超参数控制训练怎样进行；过拟合是越来越适应训练样例，却没在新问题上保持效果。**像把几道练习背熟，换问法或换主题就不会做。

## 为什么需要它

训练 loss 下降容易给人“模型已经更好”的印象。还需要看验证表现、基座对照和实际任务，才能判断是有效适配、没变化还是退步。

理解学习率、步数与长度，也能在报错和资源不足时做有依据的调整，而不是把所有数值同时改大。

## 用 MindVault 走一遍

本库真实选修的默认设置只是教学起点，不是对本机任务调优后的推荐：

| 设置 | 默认值 | 意义 |
| --- | --- | --- |
| learning_rate | 2e-4，即 0.0002 | 更新幅度相关参数 |
| steps | 8 | 优化器更新次数 |
| batch_size | 1 | 每次用一个示例 |
| max_length | 256 | 模板化完整样本允许长度 |
| rank/alpha | 4/8 | LoRA 容量与缩放 |
| precision | FP32 | 数值表示 |
| seed | 42 | 固定部分随机过程 |

train 有十二条，当前循环每步用一条，默认八步只访问前八条，不等于把训练集完整跑一遍。epoch 常指完整遍历数据一次；当前脚本按步数运行，没有独立 epoch 参数。

用虚构曲线理解过拟合，**不是本次真实训练结果**：

| 更新步数 | 训练 loss | 验证 loss |
| --- | --- | --- |
| 20 | 1.4 | 1.5 |
| 40 | 0.9 | 1.2 |
| 80 | 0.4 | 1.6 |

继续训练时训练集更贴合，验证却变差，是需要检查过拟合的信号；也要排查样本太少、数据分布和随机波动。不能凭一条曲线认定唯一原因。

可先用玩具 LoRA 固定步数和 seed，只改变学习率，比较训练与验证误差。实践二现有示例同时改步数与学习率，只用于观察流程；若要归因，重新设计单变量对照。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 保存基座 | 固定验证题与规则 | 训练前表现 |
| 选起点 | 资源限制、数据长度 | 明确配置 |
| 只改一个因素 | 如学习率 | 可解释的训练对照 |
| 看验证和输出 | loss、实际回答 | 泛化信号与失败样例 |
| 固定方案后测试 | 保留题 | 同题基座/适配对比 |

早停是验证不再改善时提前结束的策略；当前真实脚本没有自动早停、保存最佳中间模型或断点续训，只保存最终适配器。

## 常见疑问

**学习率太大有什么表现？**可能震荡或数值发散；太小可能在预算内变化很小。仅看步数不能判断学习是否有效。

**长样本会自动裁掉吗？**本库会报错，不静默截掉回答。缩短样本或确认资源后调长度，避免标签全无或关键内容丢失。

**rank 翻倍等于质量翻倍吗？**没有这种关系。容量、过拟合和资源要共同评估。

**固定 seed 保证结果完全一样吗？**不保证，依赖、设备和外部实现仍可能带来差异。继续记录版本和实测。

**验证 loss 是所有 Token 合并后的平均吗？**当前先按示例得到回答损失，再对示例平均，不是把所有样本 Token 数合并加权。比较时保持相同口径。

## 小练习与自测

**题目：**训练 loss 降、验证 loss 升，直接继续加倍训练步数合适吗？

**参考答案：**先检查数据与评估，可能需要减少训练、改数据或设置，不应把更多步数当必然改善。

**练习：**玩具实验固定 400 步与 seed，对比学习率 0.01 和 0.03，记录误差；它只支持小矩阵结论，不能推断真实模型最佳学习率。
