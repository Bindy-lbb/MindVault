# 函数

[卡片目录](README.md) · [课程入口](../20-课程笔记/第一阶段-线上课程与阅读顺序.md)

## 一句话解释

**函数把一组步骤命名，按约定接收输入，并可把结果返回给调用方。**像给“取出笔记标题”安排一套固定工序，之后换笔记也能复用。

## 为什么需要它

文件读取、请求构造、回答提取和结果校验是不同职责。拆成函数后，可以分别理解和检查，也更容易定位错误发生在哪一步。

定义函数只是准备能力，调用才会执行函数体。名字相似不代表参数和返回值相同，先看输入输出约定。

## 用 MindVault 走一遍

下面是完整的自写 Python 练习，只处理文字，不读文件、不调用模型：

```python
def clean_title(text):
    cleaned = text.strip()
    if not cleaned:
        return "未命名"
    return cleaned

title = clean_title("  Token  ")
print(title)
print(clean_title("   "))
```

输出 Token 和未命名。def 定义函数；text 是形参；调用时的字符串是实参；return 把结果交回 title 或 print。

| 名称 | 作用 |
| --- | --- |
| 函数名 | 表示做什么 |
| 参数 | 调用方传什么 |
| 函数体 | 实际步骤 |
| 返回值 | 后面代码能继续使用什么 |
| 副作用 | 如打印、写文件或发请求 |

print 是显示，return 是交回值。若函数只 print 而没有显式 return，正常执行到结尾通常返回 None；终端看到文字，不代表变量拿到了文字。

项目 01 的 read_note(source) 接受 Path，返回笔记字典；save_json(note,destination) 负责写新文件。项目 02 的 build_payload(...) 返回字典，call_api(...) 才发网络请求。这样的分工也让 preview 可以只构造、不发送。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 定义 | 名称、参数与步骤 | 可调用函数 |
| 调用 | 具体输入 | 函数开始执行 |
| 判断处理 | 当前参数和局部变量 | 中间结果 |
| return | 要交回的数据 | 调用方得到值 |
| 后续使用 | 返回值 | 保存、打印或下一步处理 |

return 后本次函数调用立即结束；函数内部局部名字通常不直接成为外部变量。

## 常见疑问

**同一函数能调用多次吗？**可以，每次传不同输入。但若函数有文件或网络副作用，要考虑重复执行的影响。

**变量与函数能同名吗？**名字可被重新绑定，但容易覆盖原函数导致“不可调用”等错误，初学避免这样写。

**写函数就是训练模型吗？**不是，这里定义的是程序行为，不修改模型参数。

**返回字典有什么好处？**调用方可以按字段继续处理，不需要从打印文字里重新猜结构。

**为什么函数抛异常？**输入不符合约定或执行失败时可以明确终止，让上层决定提示、恢复或停止。
