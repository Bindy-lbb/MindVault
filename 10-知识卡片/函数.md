# 函数

[知识卡片目录](README.md) · [学习地图](../学习地图.md)

## 一句话解释

**函数把一段处理步骤起一个名字，调用时可以传入信息，并把结果返回给调用者。**Python 用 `def` 定义函数，用 `return` 返回值。[参考：CS50P 函数与返回值](https://cs50.harvard.edu/python/notes/0/)

## 用生活里的事理解

像一台贴着用途标签的小机器：放入标题，得到带状态的标题。以后处理另一个标题，可以重复调用这台机器。

## 一个具体例子

```python
def make_label(title):
    return f"待读：{title}"


result = make_label("Token")
print(result)
```

这份自拟示例输出 `待读：Token`。

- `make_label`：函数名。
- `title`：函数定义中的参数，用于接收调用时传入的值。
- `"Token"`：这次调用实际传入的内容。
- `return`：把结果交回，便于后续继续使用。

## 放到 MindVault 中有什么用

可以把“读取笔记”“整理字段”“保存 JSON”各自写成函数，再组合成一个小程序。函数的“参数”是编程术语，要与 [模型参数](参数.md) 区分。

## 容易误解的地方

- 定义函数后，通常还需要调用它，函数体才会执行。
- `print` 用来显示信息，`return` 用来交回结果；只打印不等于把这个值返回了。
- 没有显式返回值的普通函数会返回 `None`。[补充：Python 函数定义](https://docs.python.org/zh-cn/3.13/tutorial/controlflow.html#defining-functions)
