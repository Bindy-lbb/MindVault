# 应用配置与密钥管理

[卡片目录](README.md) · [第五阶段课程](../20-课程笔记/第五阶段-评估与部署课程及实践顺序.md)

## 一句话解释

**配置描述应用怎样运行，密钥证明调用权限；把两者分开，便于换环境和保护账户。**像地址可以写在操作说明里，门禁密码不放在公开说明旁边。

## 本项目的配置

JSON 写资料目录、索引路径、日志路径、端口和切分参数。相对路径按配置文件所在目录解释，不随终端当前位置变化。服务地址固定为 127.0.0.1，不提供外网监听开关。

离线检索服务不需要 API Key，也不会读取密钥。以后接入真实模型时沿用环境变量或部署平台的密钥管理，不把凭据加入 JSON、发布包或日志。

Streamlit 官方文档要求密钥文件不进入 Git，并介绍平台设置中的密钥管理。[部署文档](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management)

## 换路径前先想清楚

把示例配置移动到另一个目录，里面的相对路径也会改含义。发布脚本会生成适配发布目录的配置；索引含绝对资料位置，移机后重新建立，不直接复制旧索引。

启动前验证字段和路径，缺少资料或端口冲突时明确报错。配置有效不等于资料内容可靠。
