# 损失函数与梯度更新

[卡片目录](README.md) · [进阶课程](../20-课程笔记/进阶阶段-模型原理本地部署与微调.md)

## 一句话解释

**损失函数给预测与目标的差异一个数值；梯度说明可训练量怎样影响损失，优化器据此更新它们。**像做练习后找出偏差，再小步调整解题方法，但数学梯度本身不理解知识真假。

## 为什么需要它

模型如何从示例“学到”行为，需要一条可计算的反馈路线：预测 → 对照目标 → 算损失 → 求梯度 → 更新参数。看懂它，也能理解为什么 loss 降低不等于所有新问题都答对。

真实语言模型训练通常对多个有效 Token 计算下一 Token 损失；本库先用三个候选和一步更新说明机制。

## 用 MindVault 走一遍

实践一将三个 logits [2,0,-1] 当作可调整的玩具数值，目标下标是 1，即第二项。softmax 得到约 [0.8438,0.1142,0.0420]。虽然模型最看好第一项，参考目标却是第二项。

交叉熵为 `-ln(目标概率)`，所以这里约为 `-ln(0.1142)=2.1698`。目标概率越大，损失越小。ln 是自然对数，不是以 10 为底。

对这个直接调整 logits 的教学问题，梯度是预测概率减目标的独热向量，即约 [0.8438,-0.8858,0.0420]。学习率 0.2 时，用“旧值减学习率×梯度”，得到约 [1.8312,0.1772,-1.0084]，目标项提高，再算损失会下降。

| 概念 | 在本例里 | 在真实训练里 |
| --- | --- | --- |
| 可调整量 | 三个 logits | 指定为可训练的权重 |
| 目标 | 第二项为正确候选 | 参考回答的下一 Token |
| 梯度 | 直接算概率差 | 经反向传播传到权重 |
| 更新 | 简单梯度下降 | 如 AdamW 等优化器 |

这里只是调三个得分，不是训练完整模型。真实脚本由框架计算因果语言模型损失，问题标签为 -100，不参与监督评分，回答仍能参考问题。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 前向 | 输入与当前参数 | 预测得分 |
| 计算损失 | 得分、正确目标 | 一个损失数值 |
| 反向 | 损失和计算关系 | 各可训练参数的梯度 |
| 更新 | 梯度、学习率、优化器状态 | 新参数 |
| 独立检查 | 新参数与验证数据 | 是否对新样本有益 |

梯度是局部变化信息，学习率太大可能越过合适区域；不是每次更新都保证全局改善。

## 常见疑问

**loss 是错误率吗？**不是。交叉熵度量对参考目标的概率，不能直接解释成“正确率 90%”。

**冻结基座是什么意思？**基座参数不更新，仍参与前向和必要的梯度传递；LoRA 参数是要优化的部分。

**训练 loss 越低越好吗？**对训练目标是更贴合，但可能记住示例或学到错误示范。还要看验证、测试与人工判断。

**为什么先清梯度？**许多框架默认累积梯度。若没有计划做梯度累积，每步更新前要清理，避免混入前面步骤。

## 小练习与自测

**题目：**目标概率从 0.1 提高到 0.5，交叉熵怎样变？

**参考答案：**约从 2.3026 降到 0.6931；这仍不能证明所有回答更可靠。

**练习：**对比实践一更新前后的数值。想试更大学习率时，遵守脚本范围并记录变化，不把一次下降推广成所有训练的保证。
