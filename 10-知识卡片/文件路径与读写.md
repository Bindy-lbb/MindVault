# 文件路径与读写

[知识卡片目录](README.md) · [学习地图](../学习地图.md)

## 一句话解释

**路径告诉程序文件在哪里；读取把文件内容变成程序中的数据，写入把数据保存到文件。**Python 的 `pathlib.Path` 可以组合路径并读取文本。[参考：pathlib 官方文档](https://docs.python.org/zh-cn/3.13/library/pathlib.html)

## 用生活里的事理解

路径像地址。知道书的标题，还需要找到书架位置才能取到正文；程序也需要正确的文件位置。

## 一个具体例子

先打开终端并切换到 MindVault 根目录，再运行这段自拟代码：

```python
from pathlib import Path

source = Path("30-项目实践") / "01-Markdown读取小程序" / "examples" / "示例笔记.md"
text = source.read_text(encoding="utf-8")
print(source.name)
print(text.splitlines()[0])
```

预期输出文件名 `示例笔记.md` 和第一行 `# 我的第一篇学习笔记`。完整练习见 [Markdown 读取小程序](../30-项目实践/01-Markdown读取小程序/README.md)。

## 相对路径与绝对路径

| 类型 | 怎么定位 | 例子 |
| --- | --- | --- |
| 相对路径 | 从当前工作目录出发 | `10-知识卡片/Token.md` |
| 绝对路径 | 给出完整位置 | `E:\my-projects\MindVault\10-知识卡片\Token.md` |

当前工作目录和脚本所在目录可能不同。排查相对路径问题时，可以查看 `Path.cwd()`。

## 读写时关注什么

- 文本编码：示例明确指定 UTF-8。
- 文件模式：`r` 读取，`w` 写入时可能覆盖已有内容，`x` 只新建并在文件已存在时报错。
- 使用 `with ... as ...` 管理打开的文件，退出代码块时关闭文件。[参考：Python 文件读写](https://docs.python.org/zh-cn/3.13/tutorial/inputoutput.html#reading-and-writing-files)

## 放到 MindVault 中有什么用

模型调用之前，程序先把 Markdown 正文读取出来。输出需要留存时，再保存成新的文件或 [JSON](JSON.md)。
