# 结构化输出与校验

[知识卡片目录](README.md) · [第二阶段课程](../20-课程笔记/第二阶段-模型API课程与实践顺序.md)

## 一句话解释

**结构化输出把回答组织为程序容易读取的字段；校验检查格式、字段与内容是否满足任务要求。**能解析 JSON、字段正确、事实可靠，是不同层面的检查。

## 用生活里的事理解

表格填写得整齐，还要看有没有漏项、内容是不是填对。JSON 格式正确，也不能替代原文核对。

## 本项目约定的格式

```json
{
  "summary": ["一句摘要"],
  "key_points": [{"point": "文章观点", "evidence": "原文中的一小段依据"}],
  "questions": ["还需要研究的问题"],
  "suggestions": ["额外学习建议"]
}
```

这是自拟的应用格式，不是服务商统一规定的摘要格式。

## 四层检查

1. 请求正常结束，内容非空且没有被长度上限截断。
2. 返回内容能解析成 JSON。
3. 必要字段存在，字段类型正确。
4. 依据片段能在正文找到，再人工核对它是否支持观点。

本项目对第四层只自动做原文子串匹配，语义是否支持结论仍需人工检查。

## 使用 JSON 模式时

DeepSeek 文档要求设置 `response_format`，在提示中明确 JSON，并提供格式示例；还需预留输出长度，处理空内容或截断等情况。[依据：JSON Output](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)

## 我的理解与验证

- [ ] 找到离线模拟数据中的四个字段。
- [ ] 改错一个字段类型，观察校验失败。
- [ ] 从观点中挑一句，核对对应依据能否支持它。
