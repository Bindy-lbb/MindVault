# Agent 记忆与上下文

[卡片目录](README.md) · [第四阶段课程](../20-课程笔记/第四阶段-工具调用与Agent课程及实践顺序.md)

## 一句话解释

**上下文是这次请求实际提供的信息；记忆是系统有选择地保存、检索并在以后重新提供的信息。**像桌面上正在看的材料与书架上的笔记。

## 三种东西不要混淆

| 内容 | 在本项目中的位置 |
| --- | --- |
| 本次短期状态 | messages、工具结果、已读依据、次数计数 |
| 外部知识 | 选定 Markdown，通过工具搜索与读取 |
| 磁盘运行记录 | trace.json、messages.json，用于人工回看 |

把 messages.json 写到硬盘，不代表下一次模型自动记住它。当前项目每次启动都新建会话，不实现跨会话自动记忆或用户画像。

HF 循环教程说明工具反馈会加入后续上下文；本库第三阶段则演示通过检索重新提供外部知识。[循环依据](https://huggingface.co/learn/agents-course/zh-CN/unit1/agent-steps-and-structure)

## 为什么上下文要筛选

工具结果不断累积会增加长度和调用成本，还可能混入过期内容。当前用返回行数与总字符预算控制，不自动总结历史。以后做压缩摘要，要检查是否遗漏来源、约束或错误状态。

“记住”与“可信”也不同：保存错误内容会让之后继续引用错误。长期信息需明确来源、更新和删除方法。

## 小练习与自测

- [ ] 指出任务中哪些内容适合保存为笔记，哪些只需临时使用。

**参考要点：**文件未必被搜索或读取，读取结果也必须进入本次模型请求。
