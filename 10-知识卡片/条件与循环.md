# 条件与循环

[卡片目录](README.md) · [课程入口](../20-课程笔记/第一阶段-线上课程与阅读顺序.md)

## 一句话解释

**条件判断决定满足什么情况才执行，循环让同样步骤处理多项输入。**像先挑出未复习的卡片，再逐张读，不必为每张卡手写一份处理代码。

## 为什么需要它

读取文件后要判断是否是 Markdown，遍历正文要找标题，处理多条观点要逐项检查。条件和循环把这些规则落实成程序步骤。

它们也帮助防止越界：如果输出已存在，就拒绝覆盖；发现目标标题后停止查找。

## 用 MindVault 走一遍

自写 Python 示例：

```python
notes = [
    {"title": "Token", "reviewed": False},
    {"title": "API", "reviewed": True},
    {"title": "上下文", "reviewed": False},
]
for note in notes:
    if not note["reviewed"]:
        print(note["title"])
```

输出 Token 和上下文。for 每次把一项赋给 note，if 根据这一项状态判断，not 将真假反转。缩进表示哪些步骤属于循环、哪些属于条件。

项目 01 逐行扫描 content.splitlines()：如果某行以 `# ` 开头且标题非空，就取标题并 break。break 退出最近一层循环，所以只取第一个符合规则的标题。

| 写法 | 用途 | 注意 |
| --- | --- | --- |
| if / elif / else | 按条件分支 | 顺序与缩进重要 |
| for | 遍历已有项目 | 适合笔记和观点列表 |
| while | 条件成立时重复 | 要保证有结束条件 |
| break | 提前离开循环 | 后续项不再处理 |
| continue | 跳过本次剩余步骤 | 继续下一项 |

比较相等用 `==`，赋值用 `=`。`if reviewed:` 判断的是当前值真假；若传来字符串 "false"，它仍是非空字符串，不会自动等同布尔 False。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 取一项 | 笔记列表 | 当前 note |
| 判断 | reviewed 等字段 | 执行或跳过 |
| 处理 | 符合条件的项目 | 显示或更新结果 |
| 继续/结束 | 剩余项目与 break 规则 | 下一项或退出 |

真实应用既要想成功路径，也要想空列表、缺字段和没有符合项时怎么办。

## 常见疑问

**没有未复习笔记时会报错吗？**这个示例只是不打印标题；是否提示“已全部复习”要另外设计。

**break 会结束整个程序吗？**这里只离开所在循环，循环后的代码仍可继续。

**循环就是 Agent 吗？**不是，普通数据遍历也有循环；Agent 还涉及模型选择行动，第四阶段再区分。

**while True 一定会永远跑吗？**如果没有 break、返回或异常等结束方式，可能持续运行；初学优先写清退出条件。

**能边遍历边随意删原列表吗？**可能跳项或行为难懂，先用新列表收集符合项更清楚。

## 小练习与自测

**题目：**把 reviewed 改成 True，示例会打印该标题吗？

**参考答案：**不会，因为 not True 为 False。

**练习：**新增一张未复习卡，再把它改为已复习，预测两次输出；观察标题查找遇到 break 后为何忽略后续标题。
