# 工具错误与恢复

[卡片目录](README.md) · [第四阶段课程](../20-课程笔记/第四阶段-工具调用与Agent课程及实践顺序.md)

## 一句话解释

**恢复是根据失败原因选择下一步，而不是原样不停重试。**像借不到书，先分清书名写错、借完了，还是系统不可用。

## 本项目的几类情况

| 情况 | 如何处理 |
| --- | --- |
| 搜索成功但结果为空 | `ok: true`、空数组；尝试其他关键词或说明依据不足 |
| 参数类型或行号不对 | 返回 `invalid_arguments`；模型可改参数，仍消耗调用次数 |
| 笔记不在允许清单 | 返回 `unknown_note`，不能自动扩大读取范围 |
| 工具未登记 | 返回 `unknown_tool`，不执行任意同名函数 |
| 资料在运行中变化 | 返回 `corpus_changed`；停止并从新快照开始 |
| API 超时或协议无效 | 保存停止记录；本项目不自动重试 |

这套错误码为教学设计。HF 的循环说明强调将行动反馈交回下一轮决策。[循环参考](https://huggingface.co/learn/agents-course/zh-CN/unit1/agent-steps-and-structure)

## 不要把异常藏成答案

读取失败不能写成“资料没有相关内容”；网络失败也不能写成“模型认为没有答案”。错误记录与正常无答案要分开看。

未来加入写入或发送工具时，重试还可能重复执行动作，需要幂等与执行状态设计；当前练习仅用只读工具。

## 小练习与自测

- [ ] 跑 `bad_arguments` 脚本演示，找出错误参数和修正后的参数。
- [ ] 观察未知笔记与空搜索的不同返回。

**问题：**搜索空结果是程序崩溃吗？

**参考要点：**不是；可以是一次正常查询，只是当前方法和资料范围没有命中。
