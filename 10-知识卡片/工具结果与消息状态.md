# 工具结果与消息状态

[卡片目录](README.md) · [第四阶段课程](../20-课程笔记/第四阶段-工具调用与Agent课程及实践顺序.md)

## 一句话解释

**工具结果是一次行动的反馈；消息状态记录任务目前走到了哪里。**像一张借书单要对应自己的取书回执，不能拿另一张回执顶替。

## 观察调用 ID 怎样对应

模型返回的 assistant 消息里包含 `tool_calls`；程序执行后追加 `role: tool` 的消息，填写同一个 `tool_call_id` 和结果，再发起下一次请求。[DeepSeek 非思考模式示例](https://api-docs.deepseek.com/guides/tool_calls/)

本项目把成功和失败结果都写成 JSON 字符串，格式分别为 `ok/data` 与 `ok/error`。失败也要回传，模型才能根据情况改参数或承认无法完成。

## 本次会话有哪些状态

模型消息、调用次数、工具返回的片段、已经读到的依据。最终引文只能来自成功 `read_note` 返回的文字，不能凭空引用没有读过的笔记。

当前脚本每次启动新建会话，不自动恢复旧的 messages.json。磁盘记录用于回看，不等于下一次模型已经记住。

本项目明确使用非思考模式。若以后开启 DeepSeek 思考模式，需要按[当前文档](https://api-docs.deepseek.com/guides/thinking_mode/)处理对应消息字段，不能只改一个开关并沿用此循环。

## 小练习与自测

- [ ] 检查模型下一轮确实拿到了前一轮结果。

**参考要点：**不知道；终端输出不会自动成为模型下一次请求的上下文。
