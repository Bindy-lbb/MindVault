# 模型调用参数

[知识卡片目录](README.md) · [第二阶段课程](../20-课程笔记/第二阶段-模型API课程与实践顺序.md)

## 一句话解释

**调用参数是发送任务时填写的设置，例如模型名称、消息、输出长度和返回方式。**改变这些请求设置，不等于更新模型权重。

## 用生活里的事理解

像下单时选择规格和数量。先确认服务支持什么，再按任务选择；同名设置在不同服务中也可能有不同约束。

## 本项目使用的设置

| 设置 | 教学用途 |
| --- | --- |
| `model` | 通过当前文档选择模型，默认 `deepseek-flash` |
| `messages` | 提供任务与正文 |
| `max_tokens` | 为生成内容设置上限，不保证一定生成到该长度 |
| `stream: false` | 等待完整响应，先学习最简单的读取方式 |
| `thinking: {"type": "disabled"}` | 本项目使用非思考模式，便于观察基础调用 |
| `response_format` | 文章整理时请求 JSON 对象输出 |

模型名和开关按 2026-10-23 的 [首次调用](https://api-docs.deepseek.com/zh-cn/)与 [思考模式文档](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)核对。字段长度含义见 [接口定义](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。

## 容易误解的地方

- 教学脚本把输出限制在 1–4096 Token，是本地练习规则，不是服务的完整能力上限。
- `temperature` 常用于调节采样，但当前 DeepSeek 思考模式下不生效；调整前先确认模型和模式。本项目暂不设置它。
- 输出因长度停止时，要检查结束原因，不能直接当成完整结果。

## 自测与参考答案

**问题：**把输出上限设为 1200，是否说明每次固定消耗 1200 个输出 Token？

**参考要点：**不是，实际用量取决于生成结果，以响应统计为准；还要考虑输入用量。
