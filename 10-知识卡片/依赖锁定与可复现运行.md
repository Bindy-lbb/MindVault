# 依赖锁定与可复现运行

[卡片目录](README.md) · [第五阶段课程](../20-课程笔记/第五阶段-评估与部署课程及实践顺序.md)

## 一句话解释

**可复现运行需要知道代码、资料、配置和环境分别是哪一版；依赖锁定减少安装时的不确定变化。**像实验要记录试剂批次，不能只有操作步骤。

## 本项目先记录什么

Python 版本、脚本摘要、题集摘要、资料文件摘要、切分与检索参数。核心运行只用标准库，不编造不存在的第三方依赖锁文件，也不把虚拟环境目录打包进 Git。

Python venv 用于隔离环境；换机器通常重新创建，不把环境文件夹当成便携安装包。[官方说明](https://docs.python.org/3.13/library/venv.html)

## 安装第三方包时再补什么

先在独立环境安装并测试，记录依赖版本。`pip freeze` 是当前环境快照，不能单凭它保证跨系统一致；更严格的安装可结合版本固定、下载文件与哈希。[pip 可重复安装指南](https://pip.pypa.io/en/stable/topics/repeatable-installs/)

即使环境完全相同，真实模型服务与生成结果也可能变化；继续保留实际模型名、时间、返回用量与失败案例。
