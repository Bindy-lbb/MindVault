# 索引更新与数据边界

[知识卡片目录](README.md) · [第三阶段课程](../20-课程笔记/第三阶段-RAG课程与实践顺序.md)

## 一句话解释

**索引是资料某一时刻的副本；数据边界规定哪些资料能被读取、检索和发送。**像通讯录备份会过期，且不能随便把所有联系人分享出去。

## 本项目的更新规则

记录选定 Markdown 的文件路径与 SHA-256。查询前重新检查，发现新增、修改或删除时拒绝继续使用旧索引；请另存新索引后重跑评估。它采用全量重建，尚未做增量更新。

LlamaIndex 文档管理提供插入、更新、删除与刷新机制；生产系统需要处理资料变化，而不仅是第一次建库。[文档管理](https://developers.llamaindex.ai/python/framework/module_guides/indexing/document_management/)

## 你的资料会去哪儿

| 操作 | 数据边界 |
| --- | --- |
| 默认关键词建库、检索、摘录 | 本地 Python，读取显式选择的目录 |
| 语义选修首次运行 | 下载模型与依赖；文本编码在本地，不使用云端 Embedding API |
| preview | 请求内容显示在本地终端，可能包含私人原文 |
| live 问答 | 问题与本次选出的片段发送至 DeepSeek |
| GitHub 同步 | 只提交挑选的学习材料；生成索引与回答放 `.local/` 并忽略 |

私有 GitHub 仓库的可见性不等于外部模型服务的数据处理规则。先用配套自写示例，换成自己的资料时只复制允许使用的 5–10 篇笔记到专用目录；排除密钥、个人隐私和无权发送的内容。

## 小练习与自测

- [ ] 在本地副本修改一行，观察旧索引被拒绝，重建后再检索。
- [ ] 增加、删除文件各一次，记录重建原因。
- [ ] 提交前确认 `.local/` 与密钥没有进入 Git 暂存区。

**问题：**把原文变成向量后就能随意公开索引吗？

**参考要点：**不能；索引可能包含原文和来源，向量也不是隐私保护承诺。
