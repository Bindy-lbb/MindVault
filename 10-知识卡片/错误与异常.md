# 错误与异常

[知识卡片目录](README.md) · [学习地图](../学习地图.md)

## 一句话解释

**语法错误表示代码写法不符合规则；异常表示程序执行时遇到了问题。**错误信息能帮助定位文件、行号、类型和原因。[参考：Python 错误和异常](https://docs.python.org/zh-cn/3.13/tutorial/errors.html)

## 用生活里的事理解

一份操作说明漏写步骤符号，像语法错误；按说明走到了地址，却发现房间不存在，像执行时遇到异常。

## 一个具体例子

这段自拟示例尝试取出尚未填写的来源，并针对这个情况显示提示：

```python
note = {"title": "Token"}

try:
    print(note["source"])
except KeyError:
    print("这篇笔记还没有填写来源")
```

预期输出 `这篇笔记还没有填写来源`。`try` 放可能出问题的操作，`except KeyError` 处理这里预期到的缺键情况。

## 排查时先看什么

1. 找到错误类型，例如缺文件的 `FileNotFoundError` 或类型不匹配的 `TypeError`。
2. 查看消息和调用栈中的文件、行号，定位相关代码。
3. 检查实际输入、路径和字段，提出一个能验证的原因。
4. 修改后，用同样的输入重跑，再检查正常情况。

## 容易误解的地方

- 语法能通过，不代表运行一定成功。
- 捕获异常后静默忽略，可能让人误以为任务成功；应说明实际发生了什么。
- 对预期问题做针对性处理，通常比把所有问题都写成“忽略错误”更便于排查。
