# 文档切分与重叠

[知识卡片目录](README.md) · [第三阶段课程](../20-课程笔记/第三阶段-RAG课程与实践顺序.md)

## 一句话解释

**切分把长资料拆成可检索的小片段；重叠让相邻片段保留一部分共同内容。**像把长地图分成几张小图，边缘重叠方便接起来。

## 一个能手算的例子

本教学脚本按行切：每块 8 行、重叠 2 行，则依次取 1–8、7–14、13–20 行。实际最后一块可能更短。行数不是 Token 数：一行也可能非常长。

太小容易把条件和结论拆开；太大可能夹入无关内容，增加上下文和成本。重叠有助于边界信息，也会引入重复片段。不存在适合所有资料的固定最佳值。

Datawhale 在知识库章节讲解文档分割；LlamaIndex 提供把文档解析为 Nodes 的工具。[教程入口](https://github.com/datawhalechina/llm-universe) · [Nodes](https://developers.llamaindex.ai/python/framework/module_guides/loading/documents_and_nodes/)

## 下一步怎样改进

先用按行切分理解来源位置，再尝试按 Markdown 标题、段落和 Token 预算分割，保留标题层级。表格、代码块尽量保持完整。用同一组问题比较，别只凭感觉选择大小。

## 小练习与自测

- [ ] 对同一份资料分别使用 8/2 和 4/1，比较片段数量与前 3 条结果。
- [ ] 找出一个被切断的解释，说明是否需要更大块或标题信息。

**问题：**重叠越多越好吗？

**参考要点：**重复会占据检索名额和上下文，需结合边界遗漏与评估结果取舍。
