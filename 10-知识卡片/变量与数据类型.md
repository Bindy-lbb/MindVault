# 变量与数据类型

[知识卡片目录](README.md) · [学习地图](../学习地图.md)

## 一句话解释

**变量是程序给值起的名字；数据类型说明这个值是什么种类，例如文字、整数或布尔值。**给变量赋值用 `=`。[参考：Python 官方入门](https://docs.python.org/zh-cn/3.13/tutorial/introduction.html)

## 用生活里的事理解

像给资料贴标签：`title` 这个名字指向标题，`reviewed` 指向是否复习。以后通过名字取到对应的值。

## 一个具体例子

下面的例子为 MindVault 自拟，可单独运行：

```python
title = "Token笔记"
priority = 1
reviewed = False

print(title)
print(type(priority).__name__)
print(reviewed)
```

预期输出：

```text
Token笔记
int
False
```

| 写法 | 类型 | 在笔记程序里的用途 |
| --- | --- | --- |
| `"Token笔记"` | `str` 字符串 | 标题、正文 |
| `1` | `int` 整数 | 优先级、条目数量 |
| `1.5` | `float` 浮点数 | 可带小数的测量值 |
| `False` | `bool` 布尔值 | 是否复习 |

## 容易误解的地方

- `"1"` 是字符串，`1` 是整数；看着相似，能做的操作可能不同。
- `=` 用于赋值，比较两个值是否相等用 `==`。
- Python 中布尔值写作 `True`、`False`；[JSON](JSON.md) 中使用小写 `true`、`false`。

## 自测与参考答案

**问题：**为什么 `reviewed = False` 不需要给 `False` 加引号？

**参考要点：**这里需要布尔值。加引号会得到字符串 `"False"`，不再是同一种数据。
