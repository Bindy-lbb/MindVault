# 变量与数据类型

[卡片目录](README.md) · [课程入口](../20-课程笔记/第一阶段-线上课程与阅读顺序.md)

## 一句话解释

**变量是程序里用来引用值的名字，数据类型决定这个值是什么、支持哪些操作。**像给资料贴标签，但标签不等于资料本身，也不意味着值永远不变。

## 为什么需要它

笔记标题是文字，字符数是数字，是否复习是布尔值。程序需要区分它们，才能正确拼接、计算与判断。

调用 API 前先把这些基础输入处理清楚，比遇到报错后猜测“模型出问题了”更有效。

## 用 MindVault 走一遍

下面是可直接运行的自写 Python 示例。代码放在 .py 文件或 Python 解释器中，不是把每行当 PowerShell 命令：

```python
title = "Token"
priority = 1
reviewed = False
source = None
print(title, priority, reviewed, source)
print(type(title).__name__)
print(priority + 1)
```

前两条输出包含 `Token 1 False None` 和 `str`，最后输出 2。`=` 表示赋值，不是数学等式；变量使用前应先赋值。

| 值 | 类型 | 用途 |
| --- | --- | --- |
| "Token" | str | 标题和正文 |
| 1 | int | 次数、优先级 |
| 0.5 | float | 近似小数 |
| False | bool | 是否已复习 |
| None | NoneType | 尚无来源等明确空值 |

`"1"` 是文字，不是数字 1。`"1"+"2"` 得到 `"12"`；`1+2` 才是 3。若确实需要数字，可用 int("1")，但无法解析的文字会报错。

注意 `bool("false")` 是 True，因为非空字符串在真假判断中为真，不会自动按英文含义转换。来自配置和网络的数据要按类型检查，不能只看外观。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 取值 | 标题、次数、状态 | 相应类型的值 |
| 命名 | 明确名字 | 后续可引用的变量 |
| 操作 | 类型支持的运算 | 新值或类型错误 |
| 转换 | 可解释的文本 | 数字等目标类型 |
| 使用 | 正确类型的数据 | 请求字段或笔记记录 |

项目 01 的 content 是 str，len(content) 得到 int。字符数与 Token 数仍然不同。

## 常见疑问

**变量类型永远固定吗？**Python 名字可以重新绑定不同类型，但随意混用会让代码难懂，教学中保持清晰用途。

**True 和 true 一样吗？**Python 布尔值首字母大写，JSON 中小写；要按所在语言区分。

**input 得到数字吗？**内置 input 通常返回字符串，要按需要转换并处理异常。

**len 是什么意思？**返回对象长度；字符串中是字符计数，列表中是元素数量。

**print 保存到知识库了吗？**只是显示输出，不等于写文件或提交 Git。
