# 参数

[卡片目录](README.md) · [课程入口](../20-课程笔记/第一阶段-线上课程与阅读顺序.md)

## 一句话解释

**模型参数是模型内部通过训练调整的数值，如权重和偏置。**“参数”在程序调用里也指传入设置，所以阅读时先问：这是模型内部数值，还是函数/API 的输入？

## 为什么需要它

以后会同时看到“7B 参数”“max_tokens 参数”和“函数参数”。如果把它们混在一起，就容易误以为把输出上限调大是在训练更大的模型。

把规模、请求设置和实际效果分别记录，才便于比较不同模型与任务。

## 用 MindVault 走一遍

像一台机器内部有很多可调旋钮，训练调整内部数值；用户操作面板选择本次任务。旋钮只是类比，真实权重不是能逐条阅读的知识卡片。

| 用法 | 指什么 | 例子 |
| --- | --- | --- |
| 模型参数 | 内部数值 | 某模型约 7B parameters |
| 函数形参 | 定义中的输入名称 | `def add_one(value)` 的 value |
| 实参 | 调用时提供的值 | `add_one(3)` 的 3 |
| API 参数 | 请求设置字段 | model、messages、max_tokens |

B 若按十亿计数，7B 约七十亿个数值，不是七十亿篇文章，也不是七十亿个可回答问题。参数规模不能直接换成完整内存、速度或准确率。

项目 02 的命令行 `--max-output-tokens 300` 会转为请求体 max_tokens=300。它改变本次输出限制，没有改变服务模型参数数量。修改提示“只写一句”也是输入变化，不更新权重。

进阶 LoRA 才展示“冻结大部分原参数、更新小部分增量参数”的机制。本阶段先记住这些词的层次，不需要手算大型矩阵。

## 每一步的输入输出

| 步骤 | 输入 | 输出 |
| --- | --- | --- |
| 读语境 | 模型说明、函数或 API 文档 | 判断参数是哪种含义 |
| 记录模型 | 模型名和必要版本 | 采用的基座/服务 |
| 记录调用 | 任务、消息和长度等设置 | 本次请求配置 |
| 观察结果 | 实际输出和用量 | 是否满足任务 |
| 如需训练 | 数据、更新目标和评估 | 参数变化的证据 |

“修改一个参数后变好”必须说明改的是哪一层，才是可复现的描述。

## 常见疑问

**参数量越大知识越多吗？**它可能有不同能力，但模型、数据和训练方法共同影响效果，不存在按参数数换文章数的通用公式。

**请求里选另一个 model 是改变权重吗？**你改的是选择哪种服务模型，不是在原模型上执行训练。

**temperature 是模型内部权重吗？**通常是解码相关的请求设置，是否支持要按服务与模式核对。

**变量也是参数吗？**变量是名字与值的关系；只有在特定函数或模型语境中才按相应用法称参数。

**把更多文字放上下文会增加参数数吗？**不会因此增加权重规模，但会改变处理长度与可能的资源消耗。

## 小练习与自测

**题目：**提示从“写详细”改成“三句话”，模型参数增加了吗？

**参考答案：**没有，改变的是本次要求。

**练习：**在一份 preview 中找出三个 API 参数，再单独写出模型标识，解释哪些内容属于输入而非权重。
