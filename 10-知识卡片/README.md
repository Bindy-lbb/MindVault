## 第一阶段：五张基础知识卡片

第一阶段全部 16 张卡片已补充新手详细讲解，覆盖五个核心概念、四个补充概念和七个 Python 基础。每张都有输入输出、疑问解答与练习答案；从[库内阅读顺序](../20-课程笔记/第一阶段-线上课程与阅读顺序.md)开始，外部教程为选读。

建议按“大模型 → Token → 上下文 → API → 幻觉”的顺序阅读。

| 卡片 | 先记住什么 |
| --- | --- |
| [大模型](大模型.md) | 根据输入生成内容的模型，能辅助整理和问答 |
| [Token](Token.md) | 模型处理文本的小单位，不固定等于一个字 |
| [上下文](上下文.md) | 这次回答实际可参考的材料，需要与长期知识区分 |
| [API](API.md) | 程序调用其他软件能力的接口和规则 |
| [幻觉](幻觉.md) | 需要发现和核对的错误或无依据生成内容 |

卡片由 AI 辅助整理，已附原始资料链接。生活类比和示例用于理解；小练习尚待自己完成。初始状态统一为“待学习”，开始阅读后改为“学习中”，需要动手验证时改为“待实践”；满足自己的验收要求后再标为“已完成”。在[Bases 学习看板](../学习看板.base)查看和修改，具体含义见[状态规则](../40-工具手册/学习状态与Bases看板.md)。

五个概念可以连起来理解：我的程序通过 **API** 调用 **大模型**，提供 **上下文**；文本会按 **Token** 处理，生成的笔记需要检查 **幻觉**。具体依据、边界和例子见各卡片。

## 后续如何写卡片

一篇笔记尽量回答一个具体问题，例如“大模型的上下文是什么？”或“检索和微调分别解决什么问题？”。

新建笔记后，插入 [知识卡片模板](../80-模板/知识卡片模板.md)。

建议保留：一句话解释、自己的例子、来源、验证情况、相关笔记。概念还没弄懂时可以标记为“待学习”，不用急着写成确定结论。

笔记名直接写问题或概念，方便搜索。在正文中关联其他笔记，可以把课程、概念和实践串起来。
