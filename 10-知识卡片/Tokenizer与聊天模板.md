# Tokenizer与聊天模板

[卡片目录](README.md) · [进阶课程](../20-课程笔记/进阶阶段-模型原理本地部署与微调.md)

## 一句话解释

**Tokenizer 把文字映射到 Token ID；聊天模板把角色、正文和特殊标记排成模型学过的格式。**

## 用例与边界

像先按约定把问答排成对话稿，再把稿子编码。`user: ...` 这种自己拼的文字不一定等于模型的官方模板。

训练与推理应使用兼容的 Tokenizer、特殊 Token 与模板。`add_generation_prompt=True` 用于提示模型开始回答；监督训练还要包含参考回答。不要重复添加模板已经包含的特殊 Token。

本库数值实验的词表是手写教学例子，不是真实 Tokenizer。真实微调脚本会检查完整对话的 Token 前缀是否与问题模板一致，再屏蔽问题部分的标签。
