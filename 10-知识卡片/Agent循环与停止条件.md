# Agent 循环与停止条件

[卡片目录](README.md) · [第四阶段课程](../20-课程笔记/第四阶段-工具调用与Agent课程及实践顺序.md)

## 一句话解释

**Agent 循环是“决定下一步 → 执行 → 看结果 → 再决定”；停止条件让任务完成或无法继续时结束。**像查资料，查到答案就整理，查不到也要知道何时停。

HF 用思考、行动、观察来讲这个过程。[循环教程](https://huggingface.co/learn/agents-course/zh-CN/unit1/agent-steps-and-structure)

## 本项目怎样计数

- `max_rounds` 限制模型请求次数，默认 6；最终回答那次也算一次。
- `max_tool_calls` 限制工具调用尝试次数，默认 6；错误参数也占一次。
- 另设消息字符预算，防止不断累积工具结果。字符数不等于 Token。

一次响应可能提出多个工具调用；本项目逐个处理，不把“请求轮数”和“工具次数”混为一谈。预算耗尽时写明停止原因，保留记录，不宣称任务完成。

## 停止与成功是两回事

`completed` 表示返回内容通过本项目格式与引文检查，仍待人工核对；`round_limit` 或 `tool_limit` 只是受控结束。超时、协议错误、无依据也是需要记录的不同结果。

本项目每次 API 等待最多 60 秒，无自动重试；次数上限不等于精确金额或端到端时长上限。
