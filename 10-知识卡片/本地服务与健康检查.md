# 本地服务与健康检查

[卡片目录](README.md) · [第五阶段课程](../20-课程笔记/第五阶段-评估与部署课程及实践顺序.md)

## 一句话解释

**本地服务是持续等待请求的程序；健康检查帮助确认进程是否响应、依赖是否可用。**像先确认图书馆开着，再确认检索系统和书库能用。

## 本项目三个接口

- `/health`：进程能否响应，属于轻量存活检查。
- `/ready`：索引与资料是否仍匹配，决定当前能否检索。
- `/search?q=...`：实际执行关键词检索，返回片段和来源。

进程活着时也可能索引过期，所以 health 成功不代表 ready 成功。资料变更后 ready/search 返回 503，重新建库后再启动；无命中是正常的 200 空结果。

## 这是什么部署

使用 Python 标准库 `http.server`，只监听 127.0.0.1，供本机学习与验证。它没有认证、TLS、限流和生产进程管理；Python 官方明确不建议把该模块直接用于生产。[官方说明](https://docs.python.org/3.13/library/http.server.html)

本例提供检索 JSON API，不是大模型权重部署或完整聊天网页。真实模型问答继续使用项目 03/04 的显式调用。
