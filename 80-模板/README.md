# 模板说明

[返回首页](../README.md)

| 模板 | 适用内容 |
| --- | --- |
| [知识卡片模板](知识卡片模板.md) | 一个概念、一个问题 |
| [课程笔记模板](课程笔记模板.md) | 一节课、一篇文章或论文 |
| [项目实践模板](项目实践模板.md) | 小项目、实验和踩坑记录 |
| [学习复盘模板](学习复盘模板.md) | 每周总结、阶段回顾 |

使用前在 Obsidian 的核心插件设置中启用“模板”，将模板文件夹设为 `80-模板`。在新笔记正文中运行“插入模板”。

模板统一提供 `status`、`type` 和 `stage`。新笔记放在学习目录中即可进入[Bases 学习看板](../学习看板.base)，模板文件本身不会进入看板。阶段默认“00 未分类”，创建后按内容修改；状态只使用[统一规则](../40-工具手册/学习状态与Bases看板.md)中的六种写法。

`{{title}}` 会替换为笔记名，`{{date:YYYY-MM-DD}}` 会替换为插入当天的日期。模板文件本身保留这些变量即可；修改模板时建议切换到源码模式。
